# NORA — visión de plataforma

NORA debe priorizar soluciones compatibles con los procesos naturales antes que intervenir el entorno para forzar un resultado.

## Principio
**Observar primero. Intervenir solo si existe evidencia suficiente de que la intervención es necesaria, segura y compatible con el ecosistema.**

## Campos explorables
- Agricultura y cultivos
- Bosques y reforestación
- Biodiversidad y ecosistemas
- Agua y cuencas
- Incendios
- Clima y microclimas
- Suelo y degradación
- Enfermedades y plagas
- Fauna y hábitats
- Ecosistemas acuáticos
- Entornos urbanos
- Observación terrestre
- Energía y recursos
- Interacciones biológicas
- Campo personalizado

## Exploración territorial
El usuario puede seleccionar una zona (por ejemplo, Eje Cafetero, Colombia). NORA construye un perfil espacio-temporal combinando variables ambientales, biológicas, productivas y de perturbación disponibles y documenta cobertura, resolución, periodo y calidad.

NORA puede evaluar especies nativas y su compatibilidad con el territorio, identificar riesgos de invasoras, estimar escenarios para cultivos y proponer combinaciones productivas que preserven biodiversidad y funcionamiento ecológico.

## Detección y respuesta
Satélite -> anomalía -> priorización -> dron/sensor -> validación -> actualización del modelo.

Las detecciones automáticas son hipótesis hasta que exista evidencia suficiente. No se afirma causalidad por una correlación.

## Energía compatible con el entorno
NORA debe buscar dónde aprovechar energía disponible naturalmente, en lugar de modificar artificialmente el entorno para aumentar una fuente concreta.

Puede comparar:
- solar: irradiancia, nubosidad, orientación, relieve, estacionalidad y restricciones ambientales;
- eólica: velocidad/dirección del viento, relieve, variabilidad y restricciones;
- hidráulica: caudal, pendiente, estacionalidad y efectos ecológicos;
- biomasa: disponibilidad y sostenibilidad, evitando incentivar pérdida de ecosistemas;
- otras fuentes: registrar y evaluar hipótesis sin asumir que son viables.

La salida no es simplemente «máxima energía». Debe ser **energía aprovechable con mínimo impacto**, incorporando restricciones ecológicas y territoriales.

## Zona inexplorada / inconclusa
Cada análisis debe producir oportunidades de investigación clasificadas como:
- evidencia insuficiente;
- resultados científicos inconclusos;
- zona poco estudiada;
- relación desconocida;
- hipótesis de NORA;
- fenómeno potencialmente anómalo.

Para cada una: evidencia disponible, variables implicadas, incertidumbre, qué datos faltan y qué observación/experimento permitiría comprobarla.

## Descubrimiento
NORA debe poder detectar patrones espacio-temporales que no encajen con modelos conocidos y elevarlos como **anomalías para investigar**, nunca como descubrimientos confirmados automáticamente.
