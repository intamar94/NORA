# NORA — Agua y restauración ecológica

## Objetivo
Usar datos ambientales y vegetación nativa para diagnosticar el estado de una fuente hídrica y comparar estrategias de restauración que reduzcan erosión, sedimentos y presión sobre el agua, priorizando soluciones basadas en el ecosistema.

## Variables candidatas
- cobertura vegetal y cambio temporal;
- vegetación riparia y conectividad;
- precipitación y temperatura;
- humedad del suelo;
- pendiente, elevación y drenaje;
- uso/cobertura del suelo;
- turbidez o proxies satelitales cuando estén disponibles;
- caudal/nivel y calidad del agua cuando existan mediciones confiables;
- incendios, deforestación, agricultura y otras perturbaciones.

## Motor de escenarios
1. Establecer línea base.
2. Detectar zonas de presión y posibles fuentes de sedimentos/contaminación.
3. Identificar especies nativas compatibles con el ecosistema local.
4. Comparar escenarios de restauración y protección.
5. Estimar cambios esperados en cobertura, erosión, humedad y presión hídrica.
6. Medir posteriormente si el territorio evoluciona como se esperaba.

NORA debe distinguir siempre entre una correlación observada y una relación causal demostrada. Las recomendaciones de calidad de agua deben requerir mediciones directas cuando el dato sea necesario para una decisión sanitaria o regulatoria.
