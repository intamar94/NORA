# NORA — Motor universal de zonas

## Flujo objetivo
Zona seleccionada → variables disponibles → fuentes/procedencia → control de calidad → análisis espacial/temporal → relaciones → anomalías → hipótesis → evaluación → hallazgos.

## Principios
- La zona es una entrada libre; ningún territorio es permanente.
- Recopilar automáticamente las variables disponibles y registrar qué falta.
- Mantener fuente, fecha, unidad, resolución y calidad de cada variable.
- Diferenciar observación, correlación, predicción e hipótesis.
- Buscar resultados reproducibles antes de elevar un hallazgo.
- Diseñar el motor para agricultura, biodiversidad, agua, energía, clima y otros dominios.

## Vercel
La recopilación, análisis, validación y pruebas se desarrollan independientemente del despliegue. Vercel queda para la integración final.
