# NORA — plan de consolidación

## Principio
NORA estudia cualquier zona. Alto Xingu es únicamente el piloto.

## Flujo del motor
1. Definir objetivo.
2. Definir o dibujar zona.
3. Inventariar variables y fuentes compatibles.
4. Recopilar automáticamente.
5. Validar cobertura, calidad, fechas, unidades y procedencia.
6. Construir mapas y series temporales.
7. Explorar relaciones, retardos y patrones espaciales.
8. Ejecutar controles de robustez y confusores.
9. Generar hipótesis reproducibles.
10. Decidir automáticamente si la evidencia es suficiente o qué prueba sigue.

## Regla de evidencia
Una correlación es una señal exploratoria, nunca un descubrimiento por sí sola. Todo resultado debe conservar fuente, variable, periodo, escala, cobertura y método.

## Estado de despliegue
No consumir despliegues mientras existan cambios estructurales pendientes. Cuando el límite externo se libere, hacer un despliegue integrado y comprobar interfaz + API + Supabase como una unidad.
